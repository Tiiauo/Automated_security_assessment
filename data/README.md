# 数据目录

运行数据由后端创建，统一保存在本目录；用户接入的源码不得被改写或删除。

| 目录 | 用途 | 提交规则 |
| --- | --- | --- |
| `allowed_sources/` | 允许接入的本地源码；须包含在系统配置的白名单中 | 仅保留内置 `demo-app/`、`demo-clean/` 和占位文件 |
| `sources/` | Git 拉取或准备的源码副本 | 仅占位文件 |
| `workspace/` | 按项目、轮次存放的本地产物与证据 | 仅占位文件 |
| `reports/` | 生成的 Markdown / HTML 报告 | 仅占位文件 |
| `runtime_logs/` | 按项目、轮次保存的运行日志 | 仅占位文件 |
| `demo-runs/` | 专项演示日志、报告与验收摘要 | 不提交 |

其他本地项目、数据库文件、报告和日志默认忽略；不要使用 `git add -f` 将运行数据加入仓库。

两个内置示例的账号与测试数据均为虚构。`demo-app` 故意包含漏洞，仅供隔离环境演示，说明见各示例的 README。
