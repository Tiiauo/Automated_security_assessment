## 常见问题

- 数据库连接被拒绝：检查 SSH 隧道、虚拟机数据库容器及 `.env` 中的连接配置；pytest 还需要建库权限。
- 沙箱连接失败：检查隧道及 `DOCKER_HOST=tcp://127.0.0.1:2375`，确认远端存在所需镜像；不能回退到本机 Docker。
- 本地源码被拒绝：将源码所在目录的绝对路径加入 `sandbox.allowed_source_root` 白名单，不绕过校验。
- 模型结果截断：检查 `llm.max_tokens` 是否在模型支持范围内，并结合上下文、调用与角色超时设置调整；失败保留日志，不接受残缺报告。
- 本地 HTTP 无法保持登录：设置 `COOKIE_SECURE=false`，从前端同源地址访问；生产 HTTPS 保持安全 Cookie。
